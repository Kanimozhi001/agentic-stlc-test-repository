# Agentic STLC Sample Test Repository

A small sample repository for demonstrating Git repository indexing and Jira-based test discovery.

## Structure
- `backend/`: Karate API feature files
- `frontend/`: Python + Playwright UI tests
- `test-data/`: reusable sample test data

These are demonstration scripts. Update URLs, credentials, selectors, and expected responses to match a real application before execution.
